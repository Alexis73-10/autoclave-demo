# Especifika Autoclave Demo

Demostración **simulada** del Software de Autoclave de Especifika S.A.S., para exposición. No hay hardware: todos los valores de sensores los genera un simulador en el navegador.

- Funciona como aplicación instalable (PWA) en Android e iOS, y **sin internet** después de abrirla una vez.
- Réplica visual de la interfaz del equipo, con ciclos completos acelerados a unos 3 minutos.
- Español por defecto; inglés, modo oscuro y los fallos de demostración en el panel oculto (pulsación larga de 3 s sobre el logo).
- Usuarios de demostración: `admin`, `ingeniero` o `tecnico`, PIN `1234`.

## Instalar

- **Android:** abrir en Chrome › menú ⋮ › *Instalar app*.
- **iOS:** abrir en Safari › *Compartir* › *Agregar a pantalla de inicio*.
- Abrir la app una vez con internet; después funciona en modo avión.
